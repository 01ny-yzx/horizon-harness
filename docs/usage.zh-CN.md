# 使用指南

[← 项目介绍](../README.zh-CN.md) · [English](usage.md)

先完成[源码安装](../README.zh-CN.md#从源码运行)。除特别说明外，下列命令均在仓库根目录、已激活虚拟环境时运行。

## 首次启动

```bash
python -m tui
```

Horizon 自动启动本地 API 服务，等待就绪后显示欢迎动画，按 Enter 进入首页。退出 TUI 时关闭自己启动的服务，本地使用不需要云端服务器。使用 `NO_ANIMATION=1 python -m tui` 可关闭欢迎页和主页动画。

首次界面默认为英文，通过 `/language` 选择 English、中文或日本語。语言设置影响菜单和提示，模型回复保留原文。

## 连接模型

1. 输入 `/models`；没有可复用模型时选择“添加模型”。
2. 用 ↑↓ 选择服务商，按 Enter 后选择具体模型。
3. 按提示填写服务商的 API Key 并保存，内置服务会自动带入地址。

保存过的具体模型直接显示在 `/models` 中，选择后复用连接。在模型选择列表中按 `Ctrl+E` 可以打开配置。自定义 OpenAI 兼容服务还需填写接口地址、模型 ID 和上下文 Token 上限。兼容性和流式能力取决于接口与模型。

每次在 `/models` 选择模型都会更新全局默认配置，重启后仍然保留。新会话创建时固定使用当时的默认模型；即使在旧会话里修改全局配置，旧会话的模型也不会改变。运行中的任务需完成或中断后才能打开模型设置。尚未保存全局默认模型时沿用 `.env` 配置，详见[开发配置](development.zh-CN.md#常用配置)。

## 工作目录

源码在 Python 导入路径中时，工作目录默认取启动时的终端目录，也可以显式指定：

```bash
python -m tui /path/to/project
```

从任意目录使用源码启动器时，填写绝对路径：

```bash
/path/to/horizon-harness/.venv/bin/python /path/to/horizon-harness/scripts/horizon.py
```

末尾可加一个目录参数；不加则保留当前终端所在目录。这是源码启动方式，不会自动安装全局 `horizon` 命令。

底栏左侧在模型后显示当前会话的工作目录，右侧显示 Horizon 版本号。恢复历史会话时沿用该会话保存的目录，文件相对路径、项目搜索、Git 和命令都基于该目录。目录不存在时明确报错，不会悄悄切回 Horizon 源码目录。

## 版本更新

安装版每次启动都会在后台检查一次正式版本，不影响进入界面。发现新版时，右下角显示“有更新 ↑”；点击版本号或输入 `/update` 可以查看。

用 ↑↓ 选择“更新并重启”或“跳过此版本”，Enter 确认。跳过后不会反复提醒同一版本，仍可通过 `/update` 手动检查。后台检查失败时静默跳过，手动检查失败时提供重试。

确认更新后先退出 TUI 并关闭本地服务，终端显示安装进度，成功后自动重新打开 Horizon。npm、Homebrew 和 curl 各自沿用原安装渠道；模型 Key、历史会话与设置不在安装目录内。任务运行中需先完成或中断任务，再进行更新。

也可以在终端执行 `horizon upgrade`。从源码运行时通过 Git 更新；无法识别安装方式的独立运行包需通过原下载渠道更新。首次获得内置更新功能，需从 1.0.0 手动升级到包含此功能的版本。

## 会话与标签页

- `/session` 选择历史会话，`/new` 新建会话。
- 历史列表中用 ↑↓ 选择会话，Enter 打开，Delete（Mac 也支持退格键）删除；鼠标点击会话可直接打开。确认框默认选“取消”，用 → 选择“删除”后按 Enter，或直接点击删除。会话、聊天记录和排队内容会永久删除，对应标签也会关闭；API Key、全局配置、长期记忆和项目文件保留。运行中的会话需先中断再删除。
- 点击标签切换，`+` 新建；悬停显示 `×`，关闭标签不会删除历史。
- 标签数量、顺序和当前选中项会保存；未发送草稿和流式片段只在本次 TUI 运行中保留。
- 模型调用失败时，已接收的用户消息及失败、中断记录仍会保留。打开历史不会重新发送消息或启动任务。
- 标题先使用第一条用户消息，再由后台模型请求概括；概括失败保留临时标题。

回答保存了相应信息时，会显示模型和耗时。流式输出需要模型接口支持；网络重连不会重发消息，进程重启不会连接回旧的模型流。

## 排队与插队

任务进行中按 Enter 将新消息加入持久化队列，确认接收成功后清空输入框。

- 排队消息显示在输入框上方；输入为空时用 ↑↓ 选择。
- 输入为空时按 Enter 打开所选消息的插队确认，再按 Enter 确认，Esc 继续排队。
- 插队将同一条消息作为补充要求，在协作检查点交给当前任务处理，不会强制杀掉任务。
- `Ctrl+R` 取回排队消息编辑；原输入草稿会暂存，`Ctrl+G` 可恢复暂存草稿。
- 也可用队列行上的按钮插队、取回或移除；已被执行器领取的消息不能再取回。

队列按 FIFO 处理。模型失败时停止继续处理，剩余消息保留；仅重启不会自动续跑。消息沿用接收时的权限，插队不会复制消息或改变权限。

## 快捷键与文字复制

以下为默认值。进入 `/help` → **快捷键设置**，用 ↑↓ 选中功能，按 Enter 后直接按下新组合键，Esc 取消。冲突或保留按键会被拒绝，保存成功后立即生效，也可以“恢复默认快捷键”。

| 快捷键 | 操作 |
| --- | --- |
| Enter | 发送，忙碌时排队 |
| Shift+Enter / Ctrl+J | 换行 |
| Ctrl+R / Ctrl+G | 取回排队消息 / 恢复草稿 |
| Esc | 在协作边界中断 |
| Ctrl+N / Ctrl+P | 新建会话 / 历史会话 |
| Ctrl+PageUp / Ctrl+PageDown | 上一个 / 下一个标签 |
| Ctrl+W | 关闭当前标签 |
| Tab | 输入框中切换权限 |
| F1 / Ctrl+Q | 帮助 / 退出 |

终端或操作系统占用组合键时，可以在设置中选择其他按键。录入界面的 Esc 用于取消，F1 和 Ctrl+Q 保留为固定入口。

拖选对话文字，松开鼠标后自动复制，支持多行、跨段落和跨屏范围。成功后显示“已复制”并取消高亮，失败时保留选区供重试。标题、标签和底部状态栏不属于正文选区；输入框保留自己的编辑选择行为。macOS 同时使用系统剪贴板和终端剪贴板路径。

## 搜索与浏览器工具

`/search` 配置 **Tavily** 搜索 API Key，与模型 Key 分开。已有配置时留空保留原 Key；保存不会发起付费搜索或远程校验，后续请求才使用连接。

浏览器自动化还需要安装 Playwright 浏览器：

```bash
python -m pip install -r requirements-browser.txt
python -m playwright install chromium
```

可用工具受配置、依赖和访问权限影响。模型与搜索服务按各自的服务方案计费。

## 权限与本地数据

默认 `read_only`。在输入框按 Tab 切换 `full_access`，普通颜色 `◆` 表示只读，红色 `◆` 表示完全访问。之后的切换不会改变已接收消息的权限。完全访问不提供容器隔离，中断也不会撤销已经完成的副作用。

macOS 默认数据目录为 `~/Library/Application Support/Horizon Runtime`；Linux 为 `$XDG_DATA_HOME/horizon-runtime`，未设置该变量时使用 `~/.local/share/horizon-runtime`。可通过 `HORIZON_USER_DATA_ROOT` 覆盖。

| 数据目录下的位置 | 内容 |
| --- | --- |
| `horizon.db` | 会话、消息、事件、队列控制及长期记忆 |
| `connections/providers.json` | 模型连接配置与密钥 |
| `connections/default-model.json` | 全局默认服务商与模型标识 |
| `connections/search.json` | 搜索配置与密钥 |
| `tui/preferences.json` | 语言与权限偏好 |
| `tui/keybindings.json` | 自定义快捷键 |
| `tui/tabs.json` | 标签中的会话 ID、顺序与选中项 |

连接目录权限为 `0700`，密钥文件为 `0600`。它们是本地文件，不是加密保险库；不要把这些文件或 `.env` 提交到仓库、放进公开截图。模型与搜索请求仍会发送到配置的外部服务。

## 连接已有 API

```bash
python -m tui --url http://127.0.0.1:8000
```

启用认证时，通过 `HORIZON_API_KEY` 提供服务密钥。可选参数为 `--api-key-header`、`--user`、`--project`。此模式使用已有服务的工作目录，不能同时传位置目录参数，退出也不会关闭该服务。
